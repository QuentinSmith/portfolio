HOW A VARIANT IS MADE

The outer shell stays 100% intact, but the entire interior changes: the level gets inverted, walls and rooms move, or walls come out entirely. The time of day shifts too.

When I changed a layout I'd often duplicate the original first, so the old idea was saved for a variant. Returning players recognize the place but have to learn it all over again.

THE FRYER HACK

I wanted a fryer for the Cat Cafe, but there wasn't one at the time. So I modeled one in ProBuilder, placed it over the sink object, and dirtied the water to a nice oily brown. Voilà, a fryer.
SYSTEM 01 · SO_LevelData.cs

Weighted level variant selection

Early on the game only had four levels, so replayability was a real problem. Variants were my answer. This system decides which version of a level loads each time, using weights, cooldowns and a pity timer.

THE HARDEST PART

Making new levels feel fun, novel and engaging with a limited set of tools and interactables, then teaching each new element in a way players would remember.

Some level ideas got cut because the interactables they needed didn't exist. Other times I found a workaround, like the Cat Cafe fryer.
